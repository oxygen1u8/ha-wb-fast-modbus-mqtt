# Wirenboard Быстрый Modbus

Веб-интерфейс для конфигурации Wirenboard
устройств с поддержкой протокола Быстрый Modbus

## Описание

Вы можете использовать этот аддон для конфигурации
и настройки Wirenboard устройств. Веб-интерфейс предлагает
использование всех возможностей протокола Быстрый Modbus,
также и стандартный Modbus. При этом приемо-передача данных
публикуется через MQTT брокер

## Конфигурация

### Аддон

Для конфигурации аддона прежде всего необходимо указать
COM-порты, на которых находятся Modbus-устройства. Для этого
перейдите во вкладку "Конфигурация" и в "Параметры"->"Serial port config"
укажите необходимое количество портов. Например, `/dev/ttyACM0`

### Веб-интерфейс

После конфигурации аддона можно приступать непосредственно к настройке шины
и устройств на ней
